COS Code

Monorepo · Auth · Billing · Realtime

A production-shaped SaaS skeleton in a pnpm/Turborepo monorepo. Next.js 16 and React 19 on the front, NestJS 11 with Prisma 7 and PostgreSQL 16 behind it. Auth runs on Redis-backed refresh-token families, background work on BullMQ, chat over Socket.IO, and payment on Stripe checkout with signed webhooks.

  • Refresh-token families in Redis — reuse detection revokes the whole family
  • BullMQ workers split from the API process, retries and dead-letter handling
  • Stripe webhooks verified by signature before a single row is touched
  • Swagger generated from the DTOs, not written by hand
  • Whole stack up with one Docker Compose file
